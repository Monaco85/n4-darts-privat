Aktuelle Aufnahme

Simulation: Klick auf die Scheibe wirft einen Dart. Er läuft durch die echte Bilderkennung.

Kameras

Einstellungen

Zahl = USB-Kamera (0, 1, 2 …), sim:0–sim:2 = Simulation, oder Pfad zu einer Videodatei.

Verhindert, dass die Kameras mitten im Spiel heller oder dunkler regeln. Die Werte werden 3 s nach dem Start übernommen – dabei sollte niemand vor der Scheibe stehen.

Weniger Bilder pro Sekunde = weniger Last für den PC. 10–15 reichen zum Spielen.
